A modern web application built with Next.js, TypeScript, and Tailwind CSS.

## Overview

Fermor is a responsive web application designed with a component-based architecture and a clean development workflow. The project uses the Next.js App Router, TypeScript for type safety, and Tailwind CSS for styling.

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- shadcn/ui
- ESLint
- npm

## Getting Started

### Prerequisites

- Node.js 18 or later
- npm

### Installation

Clone the repository:

```bash
git clone https://github.com/aditya-c7/fermor.git
cd fermor
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Scripts

| Command | Description |
| --- | --- |
| `npm run dev` | Starts the development server |
| `npm run build` | Creates a production build |
| `npm run start` | Starts the production server |
| `npm run lint` | Runs ESLint |

## Project Structure

```text
app/        Application routes and pages
components/ Reusable UI components
lib/        Utility functions and shared logic
```

## Deployment

Deploy the application on Vercel:

1. Push the repository to GitHub.
2. Import the repository into Vercel.
3. Configure environment variables, if required.
4. Deploy the project.
